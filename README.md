# now.you.see.me.👁️

A Chrome extension that adds a touch of visual chaos to your web browsing experience by making all the text blink—and disappear. Why read the news when you can *watch it fade away*?

## ✨ What It Does

1. Makes all text on the page **blink** and eventually **vanish**.
2. Because nothing says modern attention span like *now you see it, now you don’t*.
3. Ideal for those who love reading... but only for a second.

## 💻 How to Install

1. Clone or download this repo
2. Unzip it somewhere fun.
3. Open Chrome and go to `chrome://extensions`.
4. Enable **Developer Mode**.
5. Click **Load Unpacked** and select the unzipped folder.
6. Refresh any page and watch it ghost you.

## 🧠 Why?

Because reality is overrated. And because sometimes, it’s more fun when the internet doesn't want to be seen.
